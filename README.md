# Finance Tracker

A small Node.js / Express app for logging income and expenses and tracking net worth.

- **Transactions:** add income and expense entries.
- **Net Worth:** add assets and liabilities, edit or delete them, and see totals and overall net worth.

Data is kept in memory, so it resets when the server restarts.

## Run it

```bash
npm install
npm start
```

Then open http://localhost:3000.
